# LOL ARENA — 롤 내전 팀 밸런스 웹사이트

## 기능
- 10명 참가자 명단 입력
- 주 포지션, 정글 가능 여부, 실력 4단계 설정
- 포지션 및 실력 점수 기반 5대5 팀 편성
- 다시 섞기, 예시 명단, 결과 복사, 인쇄/PDF
- 외부 라이브러리 없이 동작하는 정적 웹사이트

## 무료 배포 방법 (GitHub Pages)
1. https://github.com 에 로그인하거나 계정을 만듭니다.
2. 새 repository를 만들고 이름을 `lol-arena` 등으로 정합니다.
3. 이 폴더 안의 `index.html`을 repository 최상위에 업로드합니다.
4. repository의 **Settings → Pages**로 이동합니다.
5. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
6. Branch는 `main`, folder는 `/(root)`를 선택하고 Save를 누릅니다.
7. 몇 분 뒤 Pages 화면에 표시되는 공개 주소를 친구들에게 공유합니다.

## 참고
- 이 버전은 서버 없이 실행되는 정적 웹사이트입니다. 누구나 링크로 페이지에 접속할 수 있지만, 참가자 명단이 서로 다른 기기 사이에서 자동으로 공유되지는 않습니다.
- 팀 편성은 입력된 실력 점수와 주 포지션을 기준으로 한 근사치이며, 실제 게임 결과나 승률을 보장하지 않습니다.
- 정글 가능 참가자가 2명 미만이면 5대5 편성을 막고 안내합니다.
